## 需要加强

1. **并发、并行与异步**：单线程事件循环通常是任务交替推进的并发，不代表多个 Python 代码片段同时在不同 CPU 核上执行。
2. **异常隔离的原因**：本实验中 `run_one` 捕获异常并返回 `CallResult`，因此 `gather` 收到的是正常结果；不是因为协程 ID 不同。
3. **Semaphore 的状态模型**：它维护可用许可数量；进入上下文时获取许可，离开时归还许可。它更像前端并发池或 `p-limit`，不是 Promise 本身。
