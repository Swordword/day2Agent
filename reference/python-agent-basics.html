Python Agent 后端最小语法

快速查语法，不替代闭卷回忆。先尝试，再查这里。

类型注解

def label(name: str, version: int) -> str:
    return f"{name}@{version}"

items: list[str] = ["search"]
maybe_timeout: int | None = None

注解主要服务类型检查器、IDE 和读者；Python 运行时默认不强制执行。

生成器

from collections.abc import Iterator

def names(items: list[str]) -> Iterator[str]:
    for item in items:
        yield item.upper()

Pydantic 模型

from pydantic import BaseModel, Field

class Task(BaseModel):
    prompt: str = Field(min_length=1)
    timeout_ms: int | None = Field(default=None, gt=0)

异步、超时与并发限制

async with semaphore:
    try:
        async with asyncio.timeout(seconds):
            value = await operation()
    except TimeoutError:
        ...

asyncio.Semaphore(n) 限制同时进入临界区的任务数；它不等于批次数量，也不创建线程。

异常边界

try:
    ...
except TimeoutError:
    ...
except ValueError as exc:
    ...
except Exception:
    raise

优先捕获具体异常。未知异常通常应记录后继续抛出，而不是静默吞掉。
