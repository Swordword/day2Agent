4. async 不等于自动并发（40 分钟）

async def 调用后产生协程；只有被 await 或安排为任务，它才会推进。用 gather 组织多个任务，用 Semaphore 限制同时占用外部资源的任务数，用 timeout 给每次调用设置边界。
