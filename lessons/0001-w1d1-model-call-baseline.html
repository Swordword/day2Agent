1. 心智模型

一次模型调用可以先看作前端熟悉的远程函数调用：

输入 + 配置 → 网络请求 → 模型计算 → 输出 + usage

但它比普通 fetch() 多三个重要变量：输出并非完全确定；输入和输出会占用 Token；模型与推理配置会显著改变质量、耗时和成本。因此，Agent 的每一步以后都必须可观察。

2. 先做闭卷基线（15 分钟）

打开根目录的 baseline.md，先回答 temperature、上下文窗口、输入/输出 Token。不会也要写当前猜测；基线的价值正是暴露盲区。

4. 跑同一个实验（40 分钟）

uv run python labs/w1d1/model_call.py
pnpm w1d1:ts

两段代码使用同一模型、同一输入和相同指标。把结果写入 baseline.md，然后各再运行两次。观察：Token 是否相同？耗时是否相同？不要急着下结论。

5. 四个数字分别回答什么

指标回答的问题
latency_ms用户等了多久？
input_tokens本轮给模型多少上下文？
output_tokens模型生成了多少内容？
total_tokens这次文本用量的总规模是多少？

注意：Token 不是字符数，也不直接等于费用。费用还取决于模型、缓存、工具等计费项。今天只建立测量习惯，不背价格。
