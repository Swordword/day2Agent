# Prompt 应被当作接口契约，而不是魔法字符串

W1D4

用户完成了 zero-shot 与 few-shot 两版需求拆解 Prompt，并通过 7 项本地测试。对“给登录页增加手机号验证码登录”和“列表要更快一点”的输出进行比较时，识别出 zero-shot 会擅自补全 API、地区、性能阈值等信息；few-shot 更能要求模型先提问，但在模糊需求上可能过度保守。

稳定结论不能来自一次输出。应固定模型、参数、测试输入和评分规则，分别比较任务覆盖、可执行性、验收可观察性、未编造信息，以及输入/输出 Token。few-shot 示例的价值是编码一个已观察到的边界，而不是简单增加长度。
